# java-lotto-precourse

> Java를 활용하여 로또 구매, 발매, 당첨 결과 및 수익률을 계산하는 간단한 콘솔 애플리케이션입니다.

## ✨ 주요 기능

| 분류 | 기능 | 세부 내용 |
| :--- | :--- | :--- |
| **구매 및 발행** | 금액 입력 및 수량 계산 | 사용자가 금액을 입력하여 로또 구입 수량을 계산하고 발행 |
| | 로또 번호 출력 | 발행된 로또 번호 목록과 수량을 출력 |
| **당첨 번호 입력** | 번호 입력 | 당첨 번호 6개와 보너스 번호 1개를 입력받음 |
| **결과 계산** | 당첨 내역 계산 | 구매 로또와 당첨 번호를 비교하여 등수별 개수 계산 |
| | 통계 및 수익률 출력 | 당첨 통계와 최종 총 수익률을 계산하여 출력 |

## 📝 구현 기능 목록

### A. 입력 기능

| 기능 | 세부 설명 |
| :--- | :--- |
| **구입 금액 입력** | 사용자에게 로또 구입 금액을 입력받는다. |
| **당첨 번호 입력** | 쉼표(,)로 구분된 6개의 당첨 번호를 입력받는다. |
| **보너스 번호 입력** | 보너스 번호 1개를 입력받는다. |

### B. 로또 발행 및 검증

| 기능 | 세부 설명 |
| :--- | :--- |
| **발행 수량 계산** | 구입 금액을 로또 가격(1,000원)으로 나누어 로또 수량을 계산한다. |
| **로또 생성** | 1부터 45 사이의 중복되지 않는 6개 숫자로 로또 1장을 발행한다. |
| **발행 로또 출력** | 발행된 로또 번호 목록을 **오름차순**으로 정렬하여 출력한다. |

### C. 당첨 및 수익률 계산
| **기능**               | **세부 설명**                                             |
|----------------------|-------------------------------------------------------|
| **당첨 내역 계산**         | 구매 로또별로 당첨 번호 일치 개수와 보너스 번호 일치 여부를 확인하여 등수를 판별한다.     |
| **총 상금 계산**          | 당첨 내역을 바탕으로 총 상금액을 계산한다.                              |
| **수익률 계산**           | (총 상금 /구입 금액) X 100을 계산하고 **소수점 둘째 자리에서 반올림**하여 출력한다. |
| **통계 출력**            | 당첨 통계(예: $3$개 일치 ($5,000$원) - $1$개)와 총 수익률을 출력한다.     |

### D. 프로그래밍 요구사항 및 설계 반영
| **기능**                  | **세부 설명**                                                                                |
| ----------------------- | ---------------------------------------------------------------------------------------- |
| **상수 분리 (하드 코딩 제거)**    | 로또 번호 범위, 가격, 개수, 수익률 계산 상수 등 모든 **하드 코딩된 값**을 `LottoConstants` 클래스에 static final로 분리한다. |
| **당첨 규칙 정의**            | 로또의 **당첨 기준, 상금, 일치 조건**을 LottoRank **Enum**을 사용하여 명확하게 정의하고 캡슐화한다.                      |
| **MVC 구조 확립** | 애플리케이션을 Controller, View, Model로 분리하고, 각 클래스의 책임을 명확히 한다.                                |

## 🧪 테스트 전략 (2주차 피드백 반영)

### 작은 단위부터 테스트 작성

핵심 **도메인 객체의 로직**에 대한 **단위 테스트**를 우선적으로 작성

* **`Lotto` 클래스:** 번호 개수, 범위, 중복 검증 로직 테스트.
* **`Lotto` 생성:** 정렬된 번호가 제대로 저장되는지 테스트.
* **`LottoRank` Enum:** 일치 개수와 보너스 번호 일치 여부에 따라 올바른 등수가 반환되는지 테스트.
* **`Result` 계산:** 총 상금, 수익률 계산 로직 테스트.
